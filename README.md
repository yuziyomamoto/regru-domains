# Парсер освобождающихся доменов REG.RU

Скрипт и автономный файл `.exe` для выгрузки освобождающихся доменов с [reg.ru/domain/new/rereg](https://www.reg.ru/domain/new/rereg) по заданной дате.

---

## Как пользоваться (без установки Python, через `.exe`)

1. Откройте файл **`config.ini`** в любом Блокноте и укажите дату:
   ```ini
   target_date = 15.10.2026
   ```
2. Запустите двойным кликом **`parser.exe`**.
3. Программа соберет все домены и сохранит их в файл `domains_15.10.2026.txt`.

> **Примечание:** Если дата не указана в `config.ini`, при запуске `parser.exe` сам спросит дату в консоли.

---

## Настройки в `config.ini`

```ini
[settings]
; Дата освобождения в формате ДД.ММ.ГГГГ
target_date = 15.10.2026

; Формат вывода: txt (только домены) или csv (со всеми характеристиками)
output_format = txt

; Имя файла (если пусто, создается автоматически: domains_ДД.ММ.ГГГГ.txt)
output_file = 

; Задержка между запросами к reg.ru в секундах (по умолчанию 3.0)
request_delay = 3.0

; Максимальное число страниц (0 — выгрузить абсолютно все страницы)
max_pages = 0
```

---

## Запуск из командной строки (для расширенного использования)

Можно запускать как `parser.exe`, так и `python3 parser.py` с аргументами:

```bash
# Указать дату напрямую
parser.exe --date 15.10.2026

# Сохранить в CSV с ценами и ставками
parser.exe --date 15.10.2026 --format csv

# Указать своё имя файла
parser.exe --date 15.10.2026 --output my_list.txt

# Выгрузить только первые 3 страницы для быстрой проверки
parser.exe --date 15.10.2026 --max-pages 3
```
